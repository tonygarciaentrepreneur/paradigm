PARADIGM RECOVERY

The one change it makes is marking a version "Keep Forever" when you inspect it — Google requires that before a download, and it also stops that version being auto-deleted.

Open this page from your GitHub Pages address (tonygarciaentrepreneur.github.io/paradigm/recover.html), in the same browser as Paradigm. It does not work as a downloaded file.
